# inatel-sync

Mantém o seu Google Agenda atualizado sozinho com:

- o Portal Acadêmico do Inatel (calendário de provas e quadro de aulas);
- o Moodle e o Moodle Code (entregas);
- o Outlook do trabalho.

Roda pelo Agendador de Tarefas do Windows, sem janela e sem depender de nada aberto.

> Em construção (versão 2.0). O passo a passo de instalação entra aqui na próxima etapa.
